# 小恐龙 PLUS · 夕阳冲刺

一款无需构建步骤的浏览器跑酷游戏。打开 `index.html` 即可游玩，也可直接托管在 GitHub Pages。

## 视听资源目录

两个子目录既保存游戏实际引用的模块，也提供可双击打开的离线展示页：

| 目录 | 打开入口 | 内容 |
| --- | --- | --- |
| `visual-models/` | [视觉模型馆](visual-models/index.html) | 33 个视觉展示：四套装扮、动作、荆棘、飞鸟、地形、道具、阴影与爆破；支持搜索、暂停、慢放和保存 PNG。 |
| `audio/` | [声音试听室](audio/index.html) | 14 个 WAV：两版 BGM 与全部在用音效；可逐个播放、停止、调音量、下载及重新合成。WAV 文件也可直接用系统播放器打开。 |

代码职责：

- `game.js`：输入、物理、碰撞、障碍与道具生成、计分和界面状态。每帧将状态交给渲染器。
- `visual-models/models.js`：所有 Canvas 绘制、角色配色、荆棘模块和飞鸟轮廓。游戏碰撞与绘制共用这里的几何定义；模型馆也直接调用它。
- `visual-models/gallery.js`：只提供模型馆的预览场景与交互，不参与游戏逻辑。跳跃演示轨迹、展台内运动鸟的循环位置、碎屑演示位置是展示数据。
- `audio/audio.js`：游戏实时合成与 WAV 导出共用的音色、旋律和事件定义。
- `audio/*.wav`：从当前音频模块导出的 44.1 kHz、16 位双声道试听文件，保留各音效的相对响度。BGM 文件是八小节带尾部淡出的片段，喷气音效是带起停的四秒片段；游戏中仍实时循环。

修改视觉模型后，游戏与展示页自动使用相同代码。修改音频后，游戏立即使用新音色；WAV 需在试听室点击“重新合成 WAV”并覆盖对应文件。也可在已安装 Node.js、Playwright 与浏览器的环境运行 `node audio/export-wav.cjs` 批量导出；`DINO_BROWSER_PATH` 可指定已有 Chromium/Edge 可执行文件。预览与导出不修改游戏存档或音量设置。

## 操作

- 空格：跳跃；空中再按一次二连跳。落地后重置跳跃次数。
- 在地面按下 ↓ 或 S：进入下蹲；松开或起跳即起身。空中重新按下会以更高的向下加速度快速落地，按住时在落地后下蹲；若下方是悬崖，则继续坠落。水平奔跑速度不受影响，持续按住跨过跳跃不会自动恢复下蹲。
- P：暂停或继续。
- 经典模式失败后，按 Enter 或点击“再来一次”重开；此时空格不会重开游戏。
- 手机和平板：使用画面下方的触屏按钮。
- 网页上方并列提供“经典模式”和“极限模式”两个按钮，默认选中经典模式；切换模式清空本轮进度并回到准备界面，再次点击当前模式不会重开。本轮未完成的极限挑战不计分。经典模式为无尽赛道，以最远距离计分。
- 网页上方的“极限模式”按钮：共用经典模式的赛道生成器，压力 `p = 1`，全程固定 3.6 倍速（1260 像素/秒），运动飞鸟同步为 360～432 像素/秒。不生成护盾或喷气背包，允许无限续命。保留前 2000 米的基础障碍适应期，以及 10000 米起悬崖两侧间距缩短 20% 的规则。
- 极限赛道总长 100000 米，仅在跑完全程时记分，以续命次数作为成绩，越少越好。同一浏览器档案保存最少续命次数及最近五次完赛成绩；0 次续命是有效最佳成绩。经典模式距离纪录与极限模式纪录分开保存。完赛后点击按钮或按 Enter 重开，空格不会重开。
- 极限模式下，点击同一区域的“重置本轮”会清空当前距离和续命次数，并暂停在 0 米；点击“继续极限挑战”后再开始奔跑。中途重置或切换模式不会产生极限完赛成绩；修改昵称不中断当前游戏。
- 极限模式每次续命都会触发与破盾相同的爆炸：碎片向外扩散，逐步粉碎视野内障碍并填平悬崖。坠崖时原地恢复到地面，不跳过赛道距离。随后提供 3 秒无敌与无障碍缓冲；普通障碍在 3 秒后从视野外恢复生成，石柱和运动飞鸟最早在 3.8 秒后生成，并保留入画前 0.8 秒的警告。

## 音乐与音效

游戏使用内置 Web Audio 合成一段原创的 124 BPM、八小节流行风格循环配乐：四拍底鼓、反拍掌声、切分低音、合成器和弦与主旋律共同驱动奔跑节奏；速度提高后会加入更密的踩镲。跳跃是轻短的键盘敲击声，警告为三声“滴滴滴”；落地、塌方、拾取护盾、护盾破碎、开始、暂停及结束也有独立音效。飞鸟没有叫声。点击“开始冒险”或首次按空格后才会播放，遵循浏览器的声音播放规则。

游戏底栏可以整体静音，并分别调节背景音乐与音效音量。音效通过独立增益和动态限幅平衡响度；跳跃敲击声有意保持轻柔。设置保存在当前浏览器，存储键同样使用 `elsasms.dino-plus.v1.` 前缀，并兼容此前单一音量设置。音频由浏览器实时合成，离线打开页面也能播放，不需要下载外部音频文件。

经典模式前 2000 米只会遇到荆棘、静止飞鸟和普通悬崖。之后加入贴地巨鸟、悬空巨鸟、青绿色运动飞鸟、组合障碍和塌方悬崖。高飞鸟与悬空巨鸟可下蹲通过；高空小鸟的碰撞判定跟随当前翅膀曲线，不再覆盖翅膀已经离开的空白区域；静止与运动高空小鸟分别以约 3.82 和 5.09 次/秒扇翅，部分时机可能出现可跳越的空隙。两种巨鸟的碰撞范围与身体、当前翅膀、尾巴、喙和脚的可见轮廓一致，包含两端。贴地飞鸟需要跳过；贴地巨鸟、长悬崖和较长的连续荆棘需要二连跳。运动飞鸟在进入视野前便开始移动，基础速度为每秒 100–120 像素，实时乘玩家倍速（3 倍时 300–360，3.2 倍时 320–384）迎面飞来，分贴地和高空两种高度。石柱或运动飞鸟进入画面前 0.8 秒，画面右侧会闪烁红色警告标志，进入画面即消失。

护盾徽章会在鸟、荆棘或悬崖附近随机出现，包括悬空静止小鸟上方、普通悬崖中间的跑道线下、高长荆棘上方，以及其他障碍旁。前三类困难场景每处的护盾基础掉落概率为 2%，其余符合条件的场景为 1%，实际概率再乘下述 k(x)；生成时的相邻护盾锚点至少相距 1800 个世界像素。运动飞鸟附近的徽章会跟着飞鸟移动，塌方附近的徽章会在地面开始下沉后出现；空旷赛道和悬空石柱不会单独掉落护盾。持有护盾时不会再出现护盾徽章，恐龙周围的圆形光圈下蹲时保持固定大小。护盾只能抵挡一次飞鸟或荆棘撞击；破盾时碎片会快速向四周飞出，画面内的障碍被波及后碎裂消失，悬崖被波及后立即填平。接下来约 3 秒赛道保持无障碍，之后普通障碍从画面外进入。运动飞鸟和悬空石柱最早在破盾 3.8 秒后恢复生成，仍保留提前警告。坠崖和撞上悬空石柱不会被护盾抵挡。

部分悬崖中央悬着从画面顶端垂下的石柱，柱底位于跑道表面上方约 50 像素，无法从上方越过。玩家可以先落入悬崖，等头部比柱底低约一个身位后，只跳一次便抵达对岸。只要仍在画面内且未碰到右侧崖壁，就可以在空中尝试跳回；触壁或整只恐龙离开画面才判定坠崖。部分石柱场景在对岸紧接一段长荆棘，需要再用二连跳越过。塌方悬崖在角色接近前始终呈现普通地面，距离约 0.3 秒路程时整块地面在约 0.22 秒内迅速沉入裂口，露出普通悬崖。

A（障碍—短悬崖—障碍）与 C（荆棘—鸟—荆棘）组合各有 12% 概率在一侧放置高荆棘：前侧 6%、后侧 6%，剩余 88% 沿用原组合，禁止同组两侧同时为高荆棘。短悬崖前后会在近处随机出现荆棘或不同高度的飞鸟，单独的短悬崖只需单跳，部分组合需要二连跳。短荆棘随机出现一至三株，以两株、三株为主，均可单跳越过；长荆棘由同一个荆棘模块交叠拼接。普通荆棘高度在 34 至 64 像素之间变化，另有多种配色。2000 米后新增高荆棘，宽 84 像素（普通单株的两倍），基准高度 116–122 像素，沿用原有荆棘模块与配色。基础障碍抽取中，普通荆棘、长荆棘、普通悬崖各让出 4 个百分点，高荆棘占 12%；组合场景仍单独抽取。旧的三角地刺和独立灌木模型均已移除。进阶赛道的荆棘占比仍低于早期版本。障碍间距随进度收紧，等待下一障碍的时间最多约 1.12 秒，同时为连续跳跃预留恢复时间。

奔跑速度从 350 像素/秒逐渐增加，在 1000 米达到 2 倍速，在 10000 米达到 3 倍速，并在 12000 米达到最高 3.2 倍速，即 1120 像素/秒。之后速度保持上限，障碍间距缓慢缩短；10000 米起，普通悬崖和塌方两侧的空地间距在原有各难度参数上统一缩小 20%，悬崖宽度与石柱在悬崖内的位置保持原值。运动飞鸟和石柱概率随压力缓慢增长，跳跃—下蹲—跳跃及混合短崖组合各维持 5% 的条件抽取概率；最小间距仍为落地和再次起跳留出时间。赛道顶栏可切换放大视图，隐藏或恢复右侧冒险档案。昵称、装扮、个人最佳和最近五次成绩保存在当前浏览器的 `localStorage` 中；同一浏览器只保留一份档案；修改昵称不会重置纪录或装扮。旧版多昵称数据首次打开时保留当时选中的昵称对应的档案。存储键统一使用 `elsasms.dino-plus.v1.` 前缀。清除浏览器站点数据会清除纪录。

## 喷气背包

喷气背包与护盾图标、拾取半径相同（19 个游戏像素），在同样的三类困难场景中每处基础掉落概率为 2%，其余场景为 1%，实际概率同样乘 k(x)。两种道具各自保留 1800 个世界像素的生成间距，两种道具独立抽取，允许同场景同时出现，图标上下分开。持有护盾仍可拾取背包；飞行中不再生成道具，背包不能叠加。

拾取后自动飞行 800 米，包含平滑起飞与降落。角色趴下、背包向后喷彩色火焰，并播放轻柔、平稳的喷气气流声。飞行中无敌，地面障碍仍正常生成和显示，跳跃和速降操作暂不生效，已持有的护盾不会消耗。落地触发彩色爆破：碎片向外扩散、逐步粉碎障碍并填平悬崖，随后约 3 秒处于保护和无障碍缓冲期；运动飞鸟和石柱最早 3.8 秒后恢复从视野外生成。落地与破盾使用同一个爆炸音效，暂停、静音和重置会同步处理喷气声。

## 本地测试

运行 `node --test --test-isolation=none tests/audio.test.cjs`，检查配乐循环、事件音效触发、飞鸟静音以及两类音量设置的持久化。

运行 `node --test --test-isolation=none tests/gameplay.test.cjs`，检查适应期、速度曲线、持续提升的难度、障碍比例、塌方下沉时机及可通过性、石柱下方单跳路线、高飞鸟的下蹲要求、巨鸟翅膀运动及轮廓碰撞范围、运动飞鸟入画前启动、预警时机、极限模式恒定参数、禁用道具、十万米完赛计分与独立纪录、石柱后长荆棘组合、跳跃—下蹲—跳跃组合、极限模式续命、经典模式失败后的重开方式，以及护盾生成、抵挡和缓冲期。

## 当前难度平衡与道具统计

道具按开局、破盾或喷气落地后的实际行进距离 x（显示米）调整：x≤1000 时 k=0；1000<x<8000 时 k=log₂(x/1000)；x≥8000 时 k=3。两种道具分别以基础概率乘 k 独立抽取。吃到护盾不重置，破盾和喷气落地同时重置两种道具的增长起点。

进阶单体池普通悬崖 7%、塌方 9%，两种运动小鸟各为 (6+4p)%；经典模式三类组合依次以 (8+2p)%、5%、5% 的条件概率尝试。此前 4× 版本的道具分布与期望对比保存在 [历史难度平衡报告](BALANCE_REPORT.md) 和 [统计 JSON](balance-results.json)，尚未按本次 3.2× 回调重算。历史可解性报告同样对应旧版。

单体障碍的计划间距公式现为 `T = max(L, min(1.12, R + B − 0.04 − 0.16p))`，保留原有 L、R、B 和悬崖两侧的后续缩距规则。
